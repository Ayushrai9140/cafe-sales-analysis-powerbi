# Café Sales Dashboard (Power BI)

Interactive dashboard analysing 9,000+ café transactions from 2023.

![Dashboard](Screenshot%202026-10-17%20230820.png)

## Features
- KPIs: Revenue, Transactions, Avg Order Value, Items Sold
- Charts: monthly trend, revenue by item, weekday, payment method, location
- Filters: Item, Payment Method

## Key insights
- Total revenue: $80K, average order value $8.83
- Salad is the top item (about 23% of revenue)
- About 31% of revenue has no recorded payment method (data quality gap)

## Tools
Excel, Power BI (DAX, data modelling)
